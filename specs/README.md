# DRIP specs

This folder documents how the DRIP extension actually works — in plain English, with no code-level jargon. It is the context/documentation layer for the project: read these files before planning or changing behavior, and update them in the same change whenever a feature's behavior changes.

**Keep it short.** One clear explanation of what each thing does, why it exists, and the step-by-step flow. No function names or file paths in the feature files.
