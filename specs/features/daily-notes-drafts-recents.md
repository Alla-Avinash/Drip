# Feature: Daily notes, drafts, and recents

## What it is

Three sidebar lists that make day-to-day note-taking and navigation quick.

## How to access it

- Three views in the left DRIP sidebar: **Daily Notes**, **Drafts**, and **Recents**.
- New daily note: the **New Daily Note** button on the Daily Notes toolbar.

## Daily notes

- A "New Daily Note" command opens (or creates) today's note in a date-based folder.
- Newly created daily notes that are closed without editing are discarded automatically.
- The Daily Notes tree groups notes by year/month.

## Drafts

- Draft notes are saved and listed in the Drafts tree.
- A draft can be opened in the Composer to continue editing.

## Recents

- Recently opened notes are tracked and listed in the Recents tree.
- Picking a recent opens the file again.

## Flow (plain steps)

1. User opens today's daily note to jot down thoughts.
2. Unfinished notes can be saved as drafts and resumed later.
3. The Recents list gives one-click access to recently opened notes.
