1. User Data Directory 
    - Make the app feel continuous, fast, and personalized across launches.
    - So it stores anything that:
        avoids recomputation
        restores UI instantly
        keeps extensions working
        preserves your workflow
    - what kind of things are in this database like folder system 
        1. User intent (your choices)
            theme, settings, shortcuts
            what you prefer the editor to behave like
        2. Workspace/session state
            what project you opened
            which files were open
            cursor positions, layout
            This is what makes VS Code “resume” instead of restart
        3. Extension ecosystem state
            installed extensions
            their internal data
            login/auth info (GitHub, Copilot, etc.)
            extension cache data
        4. Performance caches
            preprocessed JS (faster startup)
            file metadata
            search/index-related data
            avoids redoing heavy work
        5. UI + runtime memory snapshot (lightweight)
            panel states
            view visibility
            sidebar selections
        6. Logs and diagnostics
            crash logs
            runtime logs
            helps debugging and stability
