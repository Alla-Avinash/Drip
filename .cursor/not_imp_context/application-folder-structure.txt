session/

    session - Things that disappear when VS Code closes.
    Examples:
        active selections
        open tabs
        current graph focus
        temporary UI state
    
    workspace/
        Things tied to the actual knowledgebase/workspace.
        the below are just examples but are not compulsarily needed features
        Examples:
            parsed document cache
            graph cache
            indexing metadata
            draft persistence
            hidden refs
            hash state

    persistence/
        Handles:
            saving/loading state
            serialization
            recovery
            migrations












settings 
    persistant settings loaded up from the knowledgebase via this module 
    also have the default settings in this module 
indexing 
    parsing logic of the .d.txt files to keep in the database
database 
    has all the schema from the settings
    will loadup the database from the persistant storage provided in the knowledgebase .driplock folder via this module
document 
    .d.txt markup and errors 
canvas  
    will have the logic for the 
    will take the required info from the database
