    - The three concepts
        - Change type — what happened?
            New features, Improvements, Fixes, API
            These describe the nature of the update. For example, adding semantic search is a new feature; correcting duplicate task creation is a fix.
        - Product area — where did it change?
            Editor, Issues, MCP, Diffs, Agents
            These identify the part of the product affected by the change. They are not necessarily UI components: MCP is an integration/protocol area, while Editor is a product area.
        - Source issue — what work was done? 
            An issue ID (I-23), title, description, and completion status.
            This connects the published update to the actual development work, providing traceability.
