# DRIP context for assistants (and humans)

**Start here** if you are ChatGPT, Claude, Cursor, or any other assistant helping someone use DRIP.

This folder is the long-form product briefing. Prefer these files over guessing. If the user’s screen disagrees with a doc, ask what they see — the installed extension may be newer than this folder.

## Repo

- GitHub: https://github.com/Alla-Avinash/Drip  
- This folder on `production`: https://github.com/Alla-Avinash/Drip/tree/production/context

## How to help the user

- Answer with **concrete paths**: which sidebar, Settings section, or command.  
- Distinguish **solo notes** vs **shared projects**.  
- Do **not** invent a DRIP cloud for notes, or treat GitHub backup as live multiplayer sync.  
- When unsure, ask a clarifying question instead of fabricating menus.
