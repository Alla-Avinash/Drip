		here when you click on the daily notes component, 
		it will create a file .d.txt with the current date as its name in the correct respective year/ month folder 
			if that years/ month folders is not present then it will create those folders..
		it will then open this file with the current date.. 
			if you write anything in that file then only that file will be saved or it will be deleted if you don't write anything new in it for the frist time it is created.. 
			this deletion is only for the first time it is created but for the second time onwards it doesn't get deleted.. 

		have a new sidecar created.. 
		have a new folder called 'daily notes' created in the .drip index similar to drafts.. as a sidecar 
		in this folder we store the daily notes stored in seperate folders with the name - 'month, year'(August, 2026) 
		so each of these notes are written by the user each day, in the last 3 months
		if the user writes anything then only these will be created or else they won't be created.. 
		it will store the daily notes for every day.. 

		it will store the temporary tasks/ daily notes for the past 3 months 
		the folder with the date/month older than the last 3 months will be deleted
